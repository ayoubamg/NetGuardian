# NetGuardian 🛡️

NetGuardian is a simple Intrusion Detection Tool built in Python.
It detects suspicious activity on your local network like ARP spoofing.

## Features
- ARP spoofing detection
- Logs alerts to a file
- Lightweight and easy to use

## Usage
```bash
python netguardian.py
```

## Requirements
- Python 3
- scapy

Install requirements:
```bash
pip install -r requirements.txt
```
